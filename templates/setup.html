QRZ.com lookup optional — requires an active QRZ XML subscription

Looks up the active caller's name, location, photo, and map coordinates. Requires a paid QRZ XML subscription to see other callsigns' info. Leave blank to disable.

RadioID.net lookup free — no account needed

Free fallback for caller name and city/state — used only when QRZ has no subscription or doesn't have the callsign. No lat/lon, so it doesn't add map pins on its own.

Use RadioID.net as a fallback
APRS.fi live position optional — requires a free APRS.fi API key

When a caller has a live APRS beacon, their real-time position is used on the map instead of QRZ's static home-station coordinates — handy for mobile/portable operators. Get a free key at aprs.fi/page/api. Leave blank to disable.

Home Assistant (MQTT) optional — requires an MQTT broker

Publishes each hotspot to Home Assistant via MQTT auto-discovery — point this at the same broker your HA instance already uses and each hotspot shows up as its own device with sensors for mode, active call, talkgroup, temperature, CPU, RSSI, and online/active/favorite-active binary sensors, with no manual HA configuration needed. Leave the broker host blank to disable.

APRS favorite alerts optional — requires your amateur radio callsign

Sends an APRS text message to yourself over APRS-IS whenever a favorite becomes active — the same mechanism used for ham-to-ham APRS messaging. No signup needed: your passcode is computed automatically from your callsign. You'll need something watching for APRS messages addressed to your callsign to actually see it — e.g. the APRSdroid app, or aprs.fi's message inbox. Leave the callsign blank to disable.
