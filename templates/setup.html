Optional dashboard cards

Each card is off by default. Where a card also needs a credential or other setting (e.g. APRS Messages' callsign), that lives in the Integrations tab — these toggles just turn the card on or off, and set its position in the Card order list (Hotspots tab).

QRZ.com lookup optional — requires an active QRZ XML subscription

Looks up the active caller's name, location, photo, and map coordinates. Requires a paid QRZ XML subscription to see other callsigns' info. Leave blank to disable.

QRZ Logbook sync optional — read-only, pulls your logged QSOs

Syncs the contacts in your QRZ Logbook into the Recent Contacts card (deduped against WSJT-X / ADIF entries) and posts a “confirmed contact” event to the Notifications card when a QSO gets confirmed. This is a separate API key from your QRZ login above — find it under QRZ Logbook → Settings → “This logbook is enabled for the QRZ API”. The XML subscription is not required for this. Turn the sync on under Cards → Notifications card sources.

RadioID.net lookup free — no account needed

Free fallback for caller name and city/state — used only when QRZ has no subscription or doesn't have the callsign. No lat/lon, so it doesn't add map pins on its own.

Use RadioID.net as a fallback
APRS.fi live position optional — requires a free APRS.fi API key

When a caller has a live APRS beacon, their real-time position is used on the map instead of QRZ's static home-station coordinates — handy for mobile/portable operators. Get a free key at aprs.fi/page/api. Leave blank to disable.

Home Assistant (MQTT) optional — requires an MQTT broker

Publishes each hotspot to Home Assistant via MQTT auto-discovery — point this at the same broker your HA instance already uses and each hotspot shows up as its own device with sensors for mode, active call, talkgroup, temperature, CPU, RSSI, and online/active/favorite-active binary sensors, with no manual HA configuration needed. Leave the broker host blank to disable.

APRS favorite alerts optional — requires your amateur radio callsign

Sends an APRS text message to yourself over APRS-IS whenever a favorite becomes active — the same mechanism used for ham-to-ham APRS messaging. No signup needed: your passcode is computed automatically from your callsign. You'll need something watching for APRS messages addressed to your callsign to actually see it — e.g. the APRSdroid app, or aprs.fi's message inbox. Leave the callsign blank to disable.

DigiPi optional — a KM6LYW DigiPi APRS/Direwolf hotspot

Polls a DigiPi over SSH for recent APRS/Direwolf activity (/run/direwolf.log) plus a live mirror of its own screen — enable the DigiPi card (Cards tab) to show it on the dashboard. Leave the IP blank to disable.

WSJT-X live QSO logging optional — plots each logged QSO on the Live map as it happens

Listens for WSJT-X's own UDP telemetry (the same feed GridTracker/ JTAlert use) — no SSH, no polling. In WSJT-X, go to File → Settings → Reporting and set "UDP Server" to this dashboard's IP address and the port below (WSJT-X's own default is 2237). Each logged QSO is added to the same QSO map layer the dashboard's Live map "Import ADIF log" feature uses — position from that QSO's own grid square (or a lookup if it didn't record one), with a line back to WSJT-X's own configured grid square.

Enable WSJT-X listening
PSK Reporter optional — a "PSK Reporter" checkbox on the Live map

Shows where your own signal was actually heard — a different question than "who's active" (there's no worldwide clutter here, it's scoped to one callsign). Set your callsign below, then enable "PSK Reporter" in the map legend. Cached 10 minutes per PSK Reporter's own request (their server actively rate-limits IPs that poll more often than that).

HamAlert optional — enable the HamAlert card in the Cards tab

Personal DXCC-needed/callsign/band alerts from your own HamAlert account — set up your alert "triggers" on their site first, then enter your HamAlert login below. Connects over their Telnet destination (outbound only, no inbound port needed on your end).

This is the dedicated Telnet password from hamalert.org → Destinations — not your regular website/app login password. HamAlert added this as a separate credential specifically for the Telnet interface.

Brandmeister optional — enables talkgroup link/unlink from each hotspot's card

A per-user Brandmeister API key lets this dashboard link/unlink static talkgroups directly from a hotspot's own card (the gear icon → Brandmeister Talkgroups section) — no need to log into Brandmeister's own site to change what a hotspot follows. Read-only status/talkgroup display (already shown on that same card) works with no key at all; this only unlocks the link/unlink controls.

Generate one from your own Brandmeister dashboard → your callsign (top right) → Profile Settings → API Keys → Add. The key is only shown once when created — copy it somewhere safe before leaving that page.
