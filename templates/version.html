Changelog
v3.37 July 2026 current
  • Fixed APRS Messages missing messages sent right around the same time as an outbound alert — the card's listener logged in "verified" (same as any real send), and APRS-IS disconnects a connection the instant a second one logs in verified as the same callsign, which is exactly what every outbound favorite alert (and the "Send test message" button) did. The listener now logs in receive-only, since it never needed to transmit — acks still go out over their own connection, unaffected. Confirmed against the real APRS-IS network before and after the fix
v3.36 July 2026
  • Fixed APRS Messages only catching your exact callsign string — the card's APRS-IS filter defaulted to an exact match per the protocol spec, so a bare callsign in Settings silently missed messages sent to any of its SSIDs (e.g. a message to "W1ZLA-9" never showed up if Settings just had "W1ZLA"). Now catches messages to any SSID of your callsign, the same way apps like APRS.fi do — each message shows which specific SSID it was addressed to, and acks are sent from that same SSID
v3.35 July 2026
  • DigiPi card — new dedicated card (Settings → Cards to enable, → Integrations for SSH connection details) for a DigiPi APRS/Direwolf hotspot: recent packet activity (direction, callsign, type, payload) polled from its Direwolf log, plus a live mirror of the DigiPi's own screen. Built and verified against a real device — supports one DigiPi for now; FLDigi and Winlink (also bundled with DigiPi) aren't covered yet

  • Standard active: green background tint + pulsing LIVE chip
  • Favorite active: amber/gold tint + pulsing ⭐ FRIEND chip + label

Fleet activity
  • Optional metrics card (off by default — Settings → General), backed by a small SQLite log of completed transmissions
  • Fleet online/total count and dashboard process uptime
  • Live-updating "last activity" — how long ago and which hotspot, ticking the same way per-card timers do
  • Mode-share breakdown — stacked bar + legend for DMR/D-Star/YSF/P25/NXDN activity over the selected time span
  • Per-hotspot / Aggregate activity chart — bucket width auto-scales to the selected span, toggle between one line per hotspot (capped at the 6 busiest, rest folded into "Other") or a summed total
  • Time span is configurable — Settings → General → "Fleet activity time span" (3/6/12/24/48 hours)
  • Card position is part of the same drag-and-drop Card order list as the hotspots (Settings → Hotspots) — can be moved anywhere among the cards
  • Rows older than the longest selectable span are pruned automatically; no manual cleanup needed
AllStarLink (ASL3) nodes
  • Second node type alongside WPSD/Pi-Star — Settings → Hotspots → Node type
  • Polled via rpt xnode over the same SSH connection, no separate credentials needed
  • Real per-linked-node keyed state (not just an aggregate "something is active" flag)
  • Linked node numbers resolved to callsigns via AllStarLink's free public stats API
  • Resolved callsigns get the same QRZ/RadioID enrichment, favorites, and APRS-alert treatment as any DMR caller
  • Card shows node number, temp/CPU, active/last-heard timers, and a live "Linked:" node list with frequency/description and location per node
ASL Favorites & Control
  • Optional card (off by default — Settings → General), inspired by AllScan
  • Favorite ASL node numbers with optional labels, added directly from the card
  • "Control from" selector picks which ASL3 hotspot originates connect/disconnect, if you have more than one
  • Live 🔴 Keyed / 🟢 Connected / Not connected status, derived from the selected hotspot's already-polled link table — no extra API calls
  • Connect/disconnect with one click via rpt cmd, confirmed against a real node
Integrations
  • QRZ.com — active caller name, city/state, photo, and map coordinates (XML subscription required)
  • RadioID.net — free fallback for caller name/location when QRZ has no subscription or doesn't have the callsign
  • APRS.fi — live beacon position for a caller, used on the map instead of QRZ's static home-station coordinates (free API key required)
  • Brandmeister — per-hotspot repeater status text and static talkgroup subscriptions, via Brandmeister's current v2 device API (needs your hotspot's Brandmeister/CCS7 ID)
  • WPSD/Pi-Star update check — flags hotspots running a git-based dashboard checkout that's behind its upstream remote (WPSD/Pi-Star nodes only)
  • AllStarLink stats.allstarlink.org — free node-to-callsign resolution for ASL3 linked nodes, no API key
  • Home Assistant (MQTT) — publishes each hotspot as an HA device via MQTT auto-discovery: online/active/favorite-active/update-available binary sensors, plus mode/call/talkgroup/temperature/CPU/RSSI/Brandmeister-status sensors (needs an MQTT broker)
  • APRS favorite alerts — sends yourself an APRS-IS text message (led by the caller's actual callsign, plus the linked talkgroup/reflector if one is known) when a favorite becomes active, with a per-favorite cooldown (needs your amateur radio callsign)
  • APRS Messages card — receives real incoming APRS-IS text messages addressed to you, with live connection status and automatic acknowledgment (shares the same callsign setting as APRS favorite alerts)
  • HF Conditions card — solar flux/A-index/K-index/sunspots and a Good/Fair/Poor band-by-band propagation table (80m–10m, day and night) from N0NBH's free feed, no API key
