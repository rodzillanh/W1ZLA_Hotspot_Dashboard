Changelog
v2.14 July 2026 current
  • APRS favorite alerts now include the talkgroup/reflector — e.g. "N1IWP active on Garage Hotspot - TGIF 603" when one is linked, falling back to the hotspot-only message when it isn't; uses a plain ASCII separator since APRS messages are meant to be readable on ASCII-only radio displays
  • Fleet activity card position is now part of Card order — the card's own draggable row appears in the same Settings → Hotspots drag list as the hotspots, so it can be moved anywhere among the cards instead of always sitting first
  • Fleet activity time span is now configurable — Settings → General → "Fleet activity time span" (3 / 6 / 12 / 24 / 48 hours); the chart's bucket width auto-scales with the selected span, and the SQLite retention window was sized off the longest option so a longer span never comes up empty from already-pruned rows
  • Fleet activity chart legibility — the x-axis now labels only hour-boundary buckets instead of every one (hover still shows the exact bucket time), and per-hotspot lines are capped at the 6 busiest, with the rest folded into a single "Other" line, since the color/dash palette was repeating and the legend was getting hard to scan past that point
  • Bugfix — fleet activity chart flashed on every refresh — the chart replayed its full draw-in animation on every 3-second poll, causing a visible flash and interrupting hover/tooltip state; updates now apply instantly with animation disabled
  • Larger callsign text — the active-call and last-heard callsign links are now bigger and bolder on the card, so they stand out more without affecting card size

  • Toolbar links toggle — hide the whole row of custom toolbar link buttons from Settings → General; the ⚙ Settings link itself always stays visible so there's still a way back into Settings
  • Direct README link — Settings → Version info tab now links straight to the README viewer instead of only via the changelog page's header link

  • Bugfix — fleet activity chart legend — the per-hotspot chart lines had no legend and reused the mode-breakdown color palette, making them look like they were plotting by mode instead of by hotspot; the chart now has its own labeled legend and a separate color palette

v2.10 July 2026
  • Bugfix — WPSD update check only looked at one of three repos — WPSD tracks WPSD-WebCode, WPSD-Scripts, and WPSD-Binaries as separate repos; the update check previously stopped after the first one found (always WebCode), so a pending update in Scripts or Binaries specifically was never detected even though WPSD's own Admin→Update page would show it. Now checks all three and flags the "⬆ update" badge if any of them is behind, with a tooltip naming which component(s)
v2.9 July 2026
  • Bugfix — WPSD/Pi-Star update check was always empty — WPSD's dashboard .git is typically owned by www-data while SSH logs in as a different user; modern git refuses to run against a repo it doesn't recognize as owned by the current user ("detected dubious ownership"), and failed silently under this command's error suppression. Confirmed directly against a real WPSD hotspot and fixed with a per-command -c safe.directory='*' override — doesn't modify the hotspot's own git config, just this one check
v2.8 July 2026
  • Bugfix — map tab freeze (root cause found) — leaflet.markercluster requires the map itself to know its maxZoom, but only the tile layers had it set; since the cluster group was added to the map before any tile layer, it threw "Map has no maxZoom specified" on every single 3-second refresh cycle, forever. Fixed by setting maxZoom explicitly on the map object itself
  • Map tab no longer refreshes in the background — the marker/line rebuild was also running every 3 seconds even after switching back to the Dashboard tab; now it only runs while the map tab is actually visible
  • Graceful CDN failure handling — if Leaflet or its marker-clustering plugin fail to load (network block, ad-blocker, offline), the map now shows a clear message instead of throwing repeatedly
  • Map sizing fix — calls Leaflet's invalidateSize() on every switch to the map tab, guarding against blank/mis-rendered tiles from the container being measured while hidden
v2.7 July 2026
  • APRS favorite alerts — sends yourself an APRS-IS text message when a favorite becomes active (Settings → Integrations), using the same mechanism as ordinary ham-to-ham APRS messaging. No signup needed — your passcode is computed automatically from your callsign. Per-favorite cooldown to avoid spamming APRS-IS
  • New dependency — adds aprslib alongside paho-mqtt as the project's second real pip dependency; same rebuild/update.sh note as v2.6 applies
  • Bugfix — the "Test Brandmeister ID" button had silently stopped working (404) since v2.6 due to a decorator lost during that edit; fixed and re-verified
v2.6 July 2026

No manual HA YAML needed — entities appear automatically once a broker host is set

All features
Dashboard
  • Live hotspot status cards, auto-refreshing every 3 seconds
  • Active call detection with pulsing 📡 ACTIVE indicator
  • Live TX timer — resets to 0:00 on each new transmission
  • Linked talkgroup / reflector — sticky, persists between calls
  • Last 5 callers as clickable QRZ.com links with name/location tooltips
  • Local time (12-hour) and UTC time, live in top-right corner
  • Customizable dashboard title
  • Dark mode and light mode with toggle
  • Customizable toolbar link buttons, with a toggle to hide the whole row
  • Card stats: mode, RSSI, BER, temperature, uptime
  • Color code — shown permanently on every DMR card (CC1, CC15, etc.)
  • Live weather — current temp, condition, and location beside the clock; click for 7-day forecast popup
  • Last heard state — cards show last caller info for 5 minutes after a call ends, with a counting-up "ago" timer
  • Time slot — shown on active DMR cards (TS1 or TS2)
Active card styling
  • Standard active: green background tint + pulsing LIVE chip
  • Favorite active: amber/gold tint + pulsing ⭐ FRIEND chip + label
  • Idle cards: no highlighting, clean appearance
Fleet activity
  • Optional metrics card (off by default — Settings → General), backed by a small SQLite log of completed transmissions
  • Fleet online/total count and dashboard process uptime
  • Live-updating "last activity" — how long ago and which hotspot, ticking the same way per-card timers do
  • Mode-share breakdown — stacked bar + legend for DMR/D-Star/YSF/P25/NXDN activity over the selected time span
  • Per-hotspot / Aggregate activity chart — bucket width auto-scales to the selected span, toggle between one line per hotspot (capped at the 6 busiest, rest folded into "Other") or a summed total
  • Time span is configurable — Settings → General → "Fleet activity time span" (3/6/12/24/48 hours)
  • Card position is part of the same drag-and-drop Card order list as the hotspots (Settings → Hotspots) — can be moved anywhere among the cards
  • Rows older than the longest selectable span are pruned automatically; no manual cleanup needed
Integrations
  • QRZ.com — active caller name, city/state, photo, and map coordinates (XML subscription required)
  • RadioID.net — free fallback for caller name/location when QRZ has no subscription or doesn't have the callsign
  • APRS.fi — live beacon position for a caller, used on the map instead of QRZ's static home-station coordinates (free API key required)
  • Brandmeister — per-hotspot repeater status text and static talkgroup subscriptions, via Brandmeister's current v2 device API (needs your hotspot's Brandmeister/CCS7 ID)
  • WPSD/Pi-Star update check — flags hotspots running a git-based dashboard checkout that's behind its upstream remote
  • Home Assistant (MQTT) — publishes each hotspot as an HA device via MQTT auto-discovery: online/active/favorite-active/update-available binary sensors, plus mode/call/talkgroup/temperature/CPU/RSSI/Brandmeister-status sensors (needs an MQTT broker)
  • APRS favorite alerts — sends yourself an APRS-IS text message (led by the caller's actual callsign, plus the linked talkgroup/reflector if one is known) when a favorite becomes active, with a per-favorite cooldown (needs your amateur radio callsign)
Friends / favorites
  • Add any callsign with an optional label
  • Amber card styling when a friend is active
  • Browser push notification when a friend keys up (HTTPS required)
  • 🔔 Enable alerts button in toolbar — explains HTTPS requirement if not met
Live map
  • Leaflet.js + OpenStreetMap, with an optional satellite tile view
  • Green pins for active callers, blue for last-5 per node, purple squares for your own hotspots
  • Click a pin for callsign, name, location, node, and (for APRS positions) a live-position note
  • Dashed distance line from hotspot to caller on active calls, labeled in miles or km
  • Caller markers cluster at low zoom to avoid overlap
  • Click "Go to card" in a caller popup to jump to and highlight its hotspot card; click a card's 📍 map link to jump back
  • Map auto-fits to all markers on first load, without fighting manual pan/zoom afterward
  • Caller chip list below map for quick scan
Settings
  • General tab — dashboard name, dark/light mode toggle, toolbar links, host stats and fleet activity card toggles
  • Weather tab — location and °F/°C unit toggle
  • Integrations tab — QRZ.com, RadioID.net, APRS.fi, Home Assistant MQTT, and APRS favorite alert credentials/toggles with connection tests
  • Hotspots tab — card order, add/edit/delete hotspots with SSH connection test, optional lat/lon and Brandmeister ID per hotspot
  • Favorites tab — callsign + optional label, add/remove, browser alerts
  • Version info tab — module hashes, uptime, changelog, feature list, and a direct README link

  • DMR, D-Star, YSF, P25, NXDN mode detection
  • Active call timeout with per-call-line timestamp check
