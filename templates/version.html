v4.29 "Croce" August 2026 current
  • VU meter now uses packet loss, a more meaningful real signal for network-relayed traffic — a live MMDVM log capture (WPSD) confirmed RSSI is never logged at all for network-received transmissions (only genuine RF-received ones, which is why the meter often had nothing but BER to fall back on), and BER itself sat at a flat 0.0% for nearly every call in that session while packet loss ranged 0-66% for otherwise-ordinary calls. Packet loss is now parsed from the same log line (and openSPOT4's equivalent "loss" field, from the same calllog event ber/rssi already come from) and slotted into the fallback chain ahead of BER — real, previously-unparsed data, not a new metric invented for this

  • VU meter's color zones no longer shift position as the bar wobbles — reported directly: the last release's gradient (scoped to position within whatever's currently lit) meant the color boundary itself moved every ~110ms tick as the natural wobble nudged the fill by a segment, reading as unrealistic/flickery. Integrations
  • QRZ.com — active caller name, city/state, photo, and map coordinates (XML subscription required)
  • RadioID.net — free fallback for caller name/location when QRZ has no subscription or doesn't have the callsign
  • APRS.fi — live beacon position for a caller, used on the map instead of QRZ's static home-station coordinates (free API key required)
  • Brandmeister — per-hotspot repeater status text and static talkgroup subscriptions, via Brandmeister's current v2 device API (needs your hotspot's Brandmeister/CCS7 ID)
  • WPSD/Pi-Star update check — flags hotspots running a git-based dashboard checkout that's behind its upstream remote (WPSD/Pi-Star nodes only)
  • AllStarLink stats.allstarlink.org — free node-to-callsign resolution for ASL3 linked nodes, no API key
  • Home Assistant (MQTT) — publishes each hotspot as an HA device via MQTT auto-discovery: online/active/favorite-active/update-available binary sensors, plus mode/call/talkgroup/temperature/CPU/RSSI/Brandmeister-status sensors (needs an MQTT broker)
  • APRS favorite alerts — sends yourself an APRS-IS text message (led by the caller's actual callsign, plus the linked talkgroup/reflector if one is known) when a favorite becomes active, with a per-favorite cooldown (needs your amateur radio callsign)
  • Notifications card — merges two independent sources into one time-sorted list: APRS Messages (real incoming APRS-IS text messages addressed to you, with automatic acknowledgment (shares the same callsign setting as APRS favorite alerts)) and HamAlert (your own personal HamAlert alert matches — DXCC needed, specific callsigns, band/mode triggers — pulled over its Telnet interface).   • HF Conditions card — solar flux/A-index/K-index/sunspots and a Good/Fair/Poor band-by-band propagation table (80m–10m, day and night) from N0NBH's free feed, no API key
