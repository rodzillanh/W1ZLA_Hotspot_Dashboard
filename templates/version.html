Changelog
v3.15 July 2026 current
  • Band Activity card — optional (Settings → General, off by default; needs a station grid square set below the toggle). Live WSPR beacon-spot activity within 500km of your station, for the same six band groups HF Conditions uses (160m, 80-40m, 30-20m, 17-15m, 12-10m, 6m) — a 24h sparkline per group from WSPR Live's free public API, a fundamentally different kind of data than HF Conditions' solar-index prediction (real observed spot counts, not a forecast). Cached ~30 minutes server-side
v3.14 July 2026
  • Band Plan card — optional (Settings → General, off by default). Static FCC Part 97.301 HF frequency/mode reference, General and Extra class privileges shown together on one card: General's range is the primary numbers, with a small note under the 4 bands where Extra differs (80m/40m/20m/15m) marking where the wider Extra segment starts. No network client — the only card in the app with no Python module of its own
  • License Quiz card — optional (Settings → General, off by default). One random Amateur Extra (Element 4) practice question at a time from the bundled 2024-2028 pool (572 questions, sourced from NCVEC's official public-domain release), auto-rotating every ~10 minutes or on demand. Click an answer to reveal correct/incorrect, plus a per-subelement (E0/E1-E9) accuracy tracker stored in the browser's own localStorage — this app has no user accounts, so progress is per-browser, not shared across devices
v3.13 July 2026
  • HF Conditions card — optional (Settings → General, off by default). Solar/band propagation data from N0NBH's free public feed, no API key: a Good/Fair/Poor table for 80m through 10m (day and night), plus Solar Flux/A-index/K-index/sunspot count and secondary stats (X-ray class, aurora, geomagnetic field, signal/noise). Polled every ~15 minutes, cached an hour server-side to match the feed's own update cadence. One card, positioned in the same Card order drag list as the other extra cards

Integrations
  • QRZ.com — active caller name, city/state, photo, and map coordinates (XML subscription required)
  • RadioID.net — free fallback for caller name/location when QRZ has no subscription or doesn't have the callsign
  • APRS.fi — live beacon position for a caller, used on the map instead of QRZ's static home-station coordinates (free API key required)
  • Brandmeister — per-hotspot repeater status text and static talkgroup subscriptions, via Brandmeister's current v2 device API (needs your hotspot's Brandmeister/CCS7 ID)
  • WPSD/Pi-Star update check — flags hotspots running a git-based dashboard checkout that's behind its upstream remote (WPSD/Pi-Star nodes only)
  • AllStarLink stats.allstarlink.org — free node-to-callsign resolution for ASL3 linked nodes, no API key
  • Home Assistant (MQTT) — publishes each hotspot as an HA device via MQTT auto-discovery: online/active/favorite-active/update-available binary sensors, plus mode/call/talkgroup/temperature/CPU/RSSI/Brandmeister-status sensors (needs an MQTT broker)
  • APRS favorite alerts — sends yourself an APRS-IS text message (led by the caller's actual callsign, plus the linked talkgroup/reflector if one is known) when a favorite becomes active, with a per-favorite cooldown (needs your amateur radio callsign)
  • APRS Messages card — receives real incoming APRS-IS text messages addressed to you, with live connection status and automatic acknowledgment (shares the same callsign setting as APRS favorite alerts)
  • HF Conditions card — solar flux/A-index/K-index/sunspots and a Good/Fair/Poor band-by-band propagation table (80m–10m, day and night) from N0NBH's free feed, no API key

Infrastructure
  • Single Docker container, no external dependencies
  • Unraid GUI template with all settings as editable fields
  • All tunables via environment variables
  • Parallel SSH polling, configurable worker count
  • Config persisted in appdata bind-mount — survives rebuilds
  • Supports Pi-Star and WPSD log locations automatically
  • DMR, D-Star, YSF, P25, NXDN mode detection
  • Active call timeout with per-call-line timestamp check
